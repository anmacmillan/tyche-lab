# Tyche Lab

A kitchen-table science experiment: which wet food suits Tyche the cat best? A/B test with settling-in days, Bayesian "cups" (Laplace's rule of succession) and a Monte Carlo comparison of the two foods.

Single static page (`index.html`). Entries are posted to a Google Form; the dashboard reads the linked sheet's published CSV. Edit the `CONFIG` block to connect them. With no CSV set it runs on demo data.
